# REAL SKY FOOT 27 — RSF 27

Prototype web jouable d'un jeu de football tactique et accessible, avec une interface de gestion de club en français.

## Lancer le prototype

Ouvrir `index.html` dans un navigateur moderne. Aucun outil de compilation ni dépendance externe n'est nécessaire.

## Fonctionnalités incluses

- Tableau de bord adaptatif : club, effectif, valeur, calendrier et activité.
- Mini-match sur terrain Canvas avec déplacement au clavier (flèches ou ZQSD), passe (E), tir (Espace) et sprint (Maj).
- Contrôles tactiles : joystick, passe et tir.
- Gestion de club, formation 4-3-3, centre de formation, conférence de presse et boutique de démonstration.
- Monnaie de jeu fictive et achats cosmétiques simulés, sans transaction réelle.
- Navigation compatible mobile et bureau, sans bibliothèque ni service externe.
